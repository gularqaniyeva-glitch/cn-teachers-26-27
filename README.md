# ЦН обучение 26/27 — панель администратора

Внутренний веб-инструмент для администраторов, работающих с большой таблицей учителей
(в перспективе — около 6000 записей). Сейчас приложение работает на тестовых данных
(50 вымышленных учителей), но спроектировано так, чтобы позже подключить Google Sheets
как источник данных без переписывания интерфейса.

## Стек

- **React 18 + TypeScript** — компонентный UI с проверкой типов.
- **Vite** — сборка и dev-сервер.
- **React Router** — навигация между разделами.
- **Zustand** — хранение состояния списка учителей.
- **Tailwind CSS v4** — стили.
- **lucide-react** — иконки.

## Структура проекта

```
src/
  types/teacher.ts          Модель данных: Teacher, ModuleResult и связанные типы
  data/constants.ts         Справочники: районы, модули, подписи для UI
  data/mockTeachers.ts       Генератор 50 тестовых учителей
  services/teacherService.ts Единая точка доступа к данным (см. ниже "Подключение Google Sheets")
  services/storage.ts        Обёртка над localStorage
  store/useTeacherStore.ts   Глобальное состояние (zustand)
  utils/stats.ts              Расчёт статистики для Главной и Статистики
  utils/teacherFilters.ts     Логика поиска, фильтрации и сортировки таблицы
  utils/csvExport.ts          Экспорт отфильтрованного списка в CSV
  components/layout/          Sidebar, Layout (навигация и каркас страниц)
  components/ui/              Переиспользуемые элементы: Badge, StatCard, Card, Bar
  components/teachers/        Таблица, фильтры, пагинация для раздела "Учителя"
  components/teacher/         Форма редактирования, результаты модулей, заметки
  pages/                      DashboardPage, TeachersPage, TeacherDetailPage, StatisticsPage
```

Компоненты, данные и логика разделены: страницы (`pages/`) собирают интерфейс из
компонентов, компоненты не знают, откуда берутся данные, а вся работа с данными
проходит через `services/` и `store/`.

## Разделы приложения

1. **Главная** — общие показатели (всего учителей, вошли/не вошли, успеваемость) и
   статистика по модулям.
2. **Учителя** — таблица с поиском (ФИО, школа, FIN, LMS ID), фильтрами (район, школа,
   тип обучения, классы, OLD/NEW, статус платформы, результат модуля), сортировкой по
   столбцам, пагинацией и экспортом в CSV.
3. **Карточка учителя** (клик по строке) — полная информация, результаты всех модулей,
   редактирование данных, внутренняя заметка.
4. **Статистика** — распределение учителей по типу обучения, классам, OLD/NEW, статусу
   платформы и результатам модулей.

## Как запустить локально

Нужен установленный [Node.js](https://nodejs.org) (LTS, версия 18+).

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

Другие команды:

```bash
npm run build    # проверка типов + сборка production-версии в папку dist/
npm run preview  # локальный просмотр собранной версии
```

Если после установки Node.js команды `npm`/`node` не находятся — закройте и снова
откройте терминал, чтобы обновился PATH.

## Данные

Сейчас данные — это 50 сгенерированных тестовых учителей (`src/data/mockTeachers.ts`).
Имена, FIN, телефоны и LMS ID полностью вымышлены и не относятся к реальным людям.
Любые изменения (редактирование карточки, заметки) сохраняются в `localStorage`
браузера, поэтому не теряются при обновлении страницы, но специфичны для конкретного
браузера/устройства.

## Подключение Google Sheets в будущем

Всё обращение к данным идёт через `src/services/teacherService.ts` — три функции:
`getTeachers()`, `getTeacherById(id)`, `updateTeacher(id, patch)`. Когда источником
данных станет Google Sheets:

1. Внутри этих трёх функций вызовы `localStorage`/генератора мока заменяются на
   запросы к Google Sheets API (например, через сервисный аккаунт или Apps Script
   веб-приложение).
2. Сигнатуры функций (аргументы и то, что они возвращают) остаются прежними — они уже
   асинхронные (`Promise`), как и будущие сетевые запросы.
3. Ни компоненты, ни страницы, ни `store/useTeacherStore.ts` менять не потребуется.

## Модули обучения
